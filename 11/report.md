# Лабораторна робота №13. Парсинг розкладу ЧНУ

## Джерела й охоплення

Дані для розрахунку взято з наданого розкладу кафедри комп’ютерних наук (копія schedule.xls). У книзі наведено курси з першого до шостого. Перелік аудиторій з комп’ютерною технікою звірено з [описом матеріальної бази](https://kkn.chnu.edu.ua/about-kafedra/mat-teh-base/). Функція пошуку публікацій читає посилання на електронні таблиці зі [сторінки розкладу кафедри](https://kkn.chnu.edu.ua/for_student/class-schedule/).

## Відтворення

На Windows з Python 3, Windows PowerShell 5.1 і драйвером Microsoft ACE OLE DB 12.0 запустіть у каталозі роботи:

```powershell
python schedule.py
python schedule.py --links
```

Перша команда аналізує додану копію розкладу автономно. Друга виводить адреси опублікованих таблиць і потребує інтернету. Програму з коментарями наведено у schedule.py, читання XLS виконує read_sheet.ps1.

## Метод

Одиниця підрахунку — одна аудиторія в конкретний день, номер пари та тиждень. Розклад має п’ять днів, сім пар на день і два тижні чергування, тобто 70 можливих пар для кожної аудиторії. Якщо кілька підгруп мають спільну лекцію, аудиторія враховується один раз. Для четвертого курсу об’єднано записи в колонках 444(1) та 444(2+с.т.н.). Онлайн-заняття не займають аудиторії.

## Висновки

1. Найбільше занять кафедри у восьмому корпусі припадає на 8-114 (34 із 70 пар), далі йдуть 8-112 (30) і 8-117 (18).
2. Серед восьми перевірених аудиторій з комп’ютерною технікою для 8-202 та 8-207 усі 70 пар залишилися без записів кафедри. Для 8-209 таких пар 68. Фактичну доступність цих приміщень можна встановити лише після врахування занять інших кафедр і бронювань.
3. Для потоку 444 найчастіше вказано 8-224 — шість пар за два тижні. Це результат для сукупності підгруп, включно з вибірковими дисциплінами.
